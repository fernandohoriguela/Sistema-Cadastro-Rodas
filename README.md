Sistema desktop desenvolvido em Python para gerenciamento de estoque de rodas automotivas, com interface gráfica e armazenamento de dados em banco SQLite.

| Funcionalidades |

Cadastro de rodas com nome, aro, preço e quantidade.

Listagem e filtragem de produtos por aro.

Registro de entrada e saída de estoque.

Controle automático de quantidades disponíveis.

Histórico de movimentações com data e quantidade.

Sistema de autenticação para acesso ao sistema.

| Tecnologias utilizadas |

Python

Tkinter — Interface gráfica.

SQLite — Banco de dados.

SQL — Consultas e manipulação de dados.

| Objetivo |

Desenvolver uma aplicação desktop para gerenciamento de estoque, aplicando conceitos de programação, integração com banco de dados, operações CRUD e desenvolvimento de interfaces gráficas.
